OPTIONAL SOUND FILES
====================

The game makes every sound in code (src/sound.cpp), so this folder can stay empty.

If you'd rather use real recordings, put a .wav (or .ogg) file here with one of these
names and the game uses it instead of the built-in sound:

  strike.wav    the cue hitting the cue ball
  click.wav     two balls hitting (the volume follows how hard they hit)
  cushion.wav   a ball bouncing off a cushion
  pocket.wav    a ball dropping into a pocket
  correct.wav   a right answer
  wrong.wav     a wrong answer
  unlock.wav    a new level or upgrade unlocked
  hover.wav     the mouse moving onto a button (keep it very short and quiet)
  button.wav    clicking a button
  combo.wav     a combo going up (it's played higher each time)
  firework.wav  a firework bursting
  levelup.wav   the XP bar filling up
  type.wav      one letter typing itself out (very short)

Free places to get them (CC0 = free to use, no credit needed):
  - kenney.nl/assets: the "Interface Sounds" pack (clicks, confirmations, errors) and
    the "Impact Sounds" pack (knocks and hits)
  - freesound.org: search for "billiard" or "pool ball" and tick the CC0 licence filter

Short files work best (under a second). Restart the game after adding one.
